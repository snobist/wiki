## Decision: link the cause-of-death rows on `/statistics` to `/cause/<category>` (v1.267.48)
- **Mechanism**: `/statistics` is one of the hubs Google crawled on 2026-10-08, but its server HTML had **zero** links to cause pages
  (the "Cause of Death" card listed Cancer 5,390, Heart Disease 3,428 … as plain text; the "Browse by Cause" nav item is not an `<a>` either).
  `/cause/cancer` is still "URL is unknown to Google". The previous report named `/statistics` (0 entity links) the weakest crawled hub.
  Making the rows anchors gives Google crawl paths from a page it already fetches to 6 cause pages + the `/cause` hub, and lets humans click through.
- Not chosen: more links from `/` — the homepage is re-crawled every ~3 days and already links `12-angry-men-1957-movie`, which is still
  unknown, so homepage links alone do not trigger discovery.
- Change: `frontend/src/components/new/StatisticsClient.tsx` (top-6 rows → `<a href="/cause/<category>">` when the category is in
  `VALID_CATEGORIES`, plus "All causes of death →" link to `/cause`), 3 CSS lines in `globals.css`; test
  `frontend/src/__tests__/statistics-cause-links.test.ts`. Commit c9dbfb1.
- Box tests: backend **363 passed**; frontend `npm run build` green; jest (new test + spanning-generations) 3 passed.
- **Harness fixes learned this run** (fold into the runbook script): backend tests need the worker package installed too
  (mount the whole clone, `pip install /repo/worker ".[test]"`, else 363 setup errors `No module named 'stillcasting_worker'`);
  containers run as root, so the clone must be removed through a container
  (`docker run --rm -v /home/ubuntu:/h python:3.11-slim rm -rf /h/predeploy-test`) before the images are removed;
  wait for `pg_isready` instead of a fixed sleep. Script copy: session scratchpad `predeploy.sh` / `predeploy-be.sh` (not persisted).
- Deploy: main fast-forwarded, tag **v1.267.48** pushed; prod HEAD = tag after ≈1.5 min, containers recreated a few minutes later,
  `/api/health` 200 throughout. Pruned 815 MB images + 2.0 GB build cache; `/data` 63 %.
- Verified live as Googlebot smartphone: `/statistics` 200, `index, follow`, links to `/cause`, `/cause/cancer`, `/cause/heart_disease`,
