## Harness notes
- The 2026-10-12/13 note holds. New gotcha: any argument after the image name in `docker run … postgres:16-alpine <arg>` goes to postgres, so it never starts and every test
  errors at setup (363 errors). Pre-pull images with `docker pull -q` and keep `docker run` args before the image name.
- The deploy wait must check container `CreatedAt`, not just `git describe` (the Action runs `git reset --hard <tag>` before the 3-minute rebuild).
  Don't use `pgrep -f "compose up"` from an ssh command line because it matches its own shell.
- `gsc-ga4-pull.py` hit a 60 s read timeout on a URL-inspection call. A rerun worked. Name scratch scripts something other than `inspect.py` (it shadows the stdlib module).
